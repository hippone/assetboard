# AI 识别（使用你自己的 API key）

默认情况下，“待确认”只用本机规则识别邮件、截图和粘贴文字。如果规则识别不准，可以在 macOS App 中接入你自己的模型服务。这个功能只在 Mac App 中可用，浏览器版没有。

## 设置

入口：“文件 → AI 识别设置…”，或“待确认”里的“配置 AI 识别”。

- **Anthropic Claude**：接口地址默认 `https://api.anthropic.com`，模型默认 `claude-opus-5-5`，可以改成你账号可用的其他 Claude 模型。
- **OpenAI 兼容接口**：填写服务商的 `/v1` 地址和支持图片的模型名，例如 OpenAI、通义千问兼容模式、Kimi 或自建网关。
- **本机模型**：可以填 `http://127.0.0.1:11434/v1`（Ollama）这类本机地址，此时可以不填 API key，资料不离开此 Mac。

点“验证并保存”会先发送一条很短的测试请求，验证通过后才保存设置。API key 存在 macOS 钥匙串（`studio.assetboard.local.ai`），其余设置存在数据目录的 `ai-settings.json`，权限 0600。网页界面拿不到 key，请求由原生部分发出。“删除 AI 设置与 API key”会删除这两项；要撤销 key 本身，需要到服务商后台操作。

## 会发送什么、何时发送

只有在你主动操作时才会发送：

| 操作 | 发送内容 |
|---|---|
| 核对页点“用 AI 识别” | 该组最近一封邮件的发件人、标题、日期和正文（最多 8000 字）；或那张截图 |
| “待确认”里点“用 AI 识别全部” | 先确认数量；每组只发送最近的一份，一次最多 100 组，可以中途停止 |
| 导入截图后自动识别 | 只在设置中勾选时生效。发送原图（长边缩到 1600 像素的 JPEG）和本机识别出的文字 |
| 粘贴文字后点“用 AI 识别” | 粘贴的文字 |

截图只在原文件仍在导入时的位置、且内容没有变化（SHA-256 一致）时才发送原图，否则只发送本机识别出的文字。附带的提示词要求模型只输出 JSON，并把材料里出现的指令当作普通内容，不去执行。

## 结果如何使用

- 模型回复被当作不可信文本处理：只保留已知字段，并限制长度；日期、金额、货币、周期和类别都要校验，无法解析的回复会被忽略，页面继续显示规则识别的结果。
- 识别结果保存在该条导入资料的 `payload.ai` 中，重新导入同一封邮件或同一张截图时会保留。
- 一份资料可以识别出多项资产（例如一张 Apple 收据里有两个订阅），核对页会逐项列出，可以分别记录。
- 模型给出的是本次付款日时，按月付或年付周期推算下一次扣款，并注明依据。
- 与规则识别一样，AI 的结果需要你核对确认后才会写入资产，写入后也可以撤销。

## 已验证与未验证（2026-09-29）

- 已验证：两种接口的请求格式（地址、请求头、图片与文字的组织方式）、错误提示、设置文件的校验与权限、图片缩放、保存结果时不覆盖原有内容，均由 `--test-ai` 通过模拟接口测试；页面流程由 `tests/ai.playwright.js` 通过模拟的原生桥接测试；模型回复在 WebKit 中的解析由 `--test-webview` 测试。
- 未验证：尚未用真实 API key 调用 Anthropic 或任何 OpenAI 兼容服务，也没有评估模型在真实账单上的准确率。各服务是否接受图片、模型名是否可用，以你账号的实际情况为准。
