# Assetboard v0.1.0

首个公开原型版本，提供 Apple Silicon macOS App。

## 功能

- 在一个大板中查看域名、服务器、订阅和数据库等演示资产。
- 搜索、折叠、查看详情，以及添加或编辑区块和资产。
- 拖动排序、调整尺寸与缩放、撤销布局变更。
- macOS 版在本机保存数据，提供上一版备份和 JSON 导出。

## 下载

下载 `Assetboard-macOS-arm64-0.1.0.zip`，解压后打开 `Assetboard.app`。需要 Apple Silicon Mac 和 macOS 12 或更新版本。

此包使用 Developer ID 签名，已通过 Apple 公证并将票据装订到 App。对从 ZIP 解压出的 App，签名校验、公证票据校验和本机 Gatekeeper 检查均通过。尚未在另一台 Mac 上做首次下载与打开验证。

ZIP 的 SHA-256：`abd71f7cec1a61313d34399a5715cb9a77bfa9a5beabe8cb68ea7d414dd9ca1f`

## 原型边界

内置内容为演示数据。管理平台入口尚未接入真实账户；没有云同步、后端或支付功能。本机资产数据以明文 JSON 保存，请按需导出备份。
